# Практическая работа №2

## Мини веб-служба и модульная архитектура

## 📌 Описание

В рамках работы реализовано приложение с модульной архитектурой, в котором функциональность расширяется за счёт подключаемых модулей без изменения ядра системы.

Каждый модуль описывается через контракт и может:

* объявлять зависимости от других модулей
* регистрировать свои сервисы
* выполнять инициализацию

Ядро приложения:

* загружает модули из конфигурации
* строит порядок запуска с учётом зависимостей
* проверяет ошибки (отсутствие модулей, циклы)
* запускает модули

---

## 🧱 Реализовано

* Контракт модуля (IModule)
* Менеджер модулей (ModuleManager)
* Загрузка модулей через reflection
* Сортировка модулей (topological sort)
* Dependency Injection (Microsoft DI)
* 3 модуля:

  * LoggingModule
  * ReportModule
  * ExportModule
